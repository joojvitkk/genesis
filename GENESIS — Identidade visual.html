07 — Iconografia & movimento

Menos ruído. Mais sinal.

A iconografia acompanha o padrão do produto em vez de disputar atenção com o relógio e os números de operação.

Lucide React

Ícones de interface

Use lucide-react, stroke entre 1,5 e 2 px, cantos arredondados e tamanho coerente. Ícones devem vir com rótulo em ações críticas; não depender de símbolo sozinho para alertas.

Princípios de movimento

Transições breves para confirmar estado, não para entreter. Prefira mudanças de opacidade e deslocamento mínimo. Nada de pulso contínuo, giro decorativo ou animações que compitam com o countdown.

150 ms
220 ms

Curva: ease-out · Propriedades: opacity, transform · Acessibilidade: respeitar prefers-reduced-motion.

08 — Tokens do sistema

Tokens semânticos consistentes.

Os nomes atuais ficam preservados. O único ajuste operacional importante é consumir brand-fg em texto de destaque sobre o canvas escuro, mantendo o vermelho original para blocos e ações.

CSS variables
tokens.css

Copie o bloco para o tema claro ou escuro do produto.

/* Tema claro */
:root[data-theme="light"] {
  --brand: #d10a0a;
  --brand-hover: #a80707;
  --brand-fg: #d10a0a;
  --brand-soft: #fdecec;
  --canvas: #f5f6f8;
  --surface: #ffffff;
  --line: #d8dde5;
  --fg: #0f172a;
}

/* Tema escuro */
